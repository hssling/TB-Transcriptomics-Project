# Data provenance

All inputs are publicly available; no identifiable human data are included.

## Primary cohort — GSE89403 (discovery)
- Source: NCBI GEO `GSE89403` (Catalysis treatment-response cohort; Thompson EG
  et al., *Tuberculosis* 2017). Whole-blood RNA-seq of adults with
  drug-susceptible, HIV-uninfected pulmonary TB on standard therapy.
- `outputs/dataset/feature_matrix.parquet` — 254 samples × 16,148 genes
  (Ensembl), normalised then log1p (note: effectively **double-logged**;
  housekeeping genes ≈ 2.5–2.7). Used for ML, deconvolution z-scores, SHAP.
- `outputs/dataset/labels.parquet` — `sample_id → label`; **label 1 = 'Not
  Cured'** (treatment failure), 0 = Definite/Probable/Possible Cure.
- `outputs/dataset/metadata.parquet` — cohort, timepoint, subject, and raw GEO
  `characteristics` (treatmentresult, sample_code, MGIT/Xpert/TGRV bacterial-load
  proxies, time-to-negativity).
- `outputs/expression/GSE89403_log2ExpGeneNames_AllSamples.csv.gz` — **single-log**
  matrix (gene symbols + Ensembl) used by `02b_deg_corrected.py` to compute
  **true log2 fold-changes** (the modelling matrix is double-logged).

### Baseline cohort definition (used throughout)
Pre-treatment (`time == DX`) samples only, one per subject → **N=90 (7 failure,
83 cure; prevalence 7.8%)**. This removes the timepoint leakage present when
multiple on-treatment samples per subject are pooled (quantified in
`01b_sensitivity_timepoints.py`).

## External cohort — GSE193979 (TANDEM)
- NCBI GEO `GSE193979` (Vianello E et al., *EBioMedicine* 2022); whole-blood
  RNA-seq, South Africa + Indonesia, good vs poor treatment outcome.
- Downloaded on demand by `06_external_validation.py`
  (`GSE193979_TANDEM_longitudinal_paper2_rawdata.txt.gz`).
- **Not usable for outcome-stratified validation**: per-patient outcomes are not
  deposited in GEO and the public count matrix is keyed by internal `RSEQ` IDs
  with no public bridge to the GSM/patient metadata. Documented in the
  Supplementary exclusion table; a label-free portability check is run instead.

## Cell-type reference — Human Protein Atlas
- `07_celltype_specificity.py` queries the HPA blood-cell atlas (Uhlén M et al.,
  *Science* 2019) per gene for blood-cell nTPM. This **granulocyte-containing**
  reference replaces the PBMC3k reference used in the original submission, which
  lacks neutrophils.

## Frozen model
- `outputs/models/model_bundle.joblib` — dict with `best_model_name`,
  `best_model`, `feature_cols`, `config`. Provided for inspection; the revision's
  reported metrics are regenerated by `01_metric_suite.py` /
  `09_recheck.py` on the leakage-free baseline cohort.

## Reproducibility notes
- Random seeds are fixed in each script (e.g. 20260613, 0, 7).
- Internet-dependent steps (MyGene symbol mapping, HPA, GSE193979) cache results
  to `DAI_Revision_2026/tables` / `external` and reuse them when offline.
