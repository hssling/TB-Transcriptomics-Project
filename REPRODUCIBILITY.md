# Baseline whole-blood transcriptomic risk stratification for unfavourable TB treatment outcome

Reproducible analysis code, processed data, frozen model, and manuscript build
scripts for the *Discover Artificial Intelligence* revision (submission
28df71d5-9f1a-4e4d-8cd3-8fcf4ef17dfb).

> **Honest summary.** This is an **exploratory** study. On a leakage-free
> baseline cohort (GSE89403 pre-treatment samples, one per subject, N=90, 7
> failures) the best model reaches ROC-AUC ≈ 0.67 (95% CI 0.38–0.89) and does
> **not** reach significance against a label-permutation null (p≈0.11). The
> defensible contributions are the methodological framework, the
> machine-learning ↔ deconvolution concordance, cell-type specificity, and a
> sex/bacterial-load confounder audit — not a deployable predictor.

## Quick start
```bash
python -m venv .venv && . .venv/bin/activate      # or conda env create -f environment.yml
pip install -r requirements.txt
python run_all.py            # reproduce everything (analysis + documents)
python run_all.py --analysis # analysis only
```
Outputs are written to `DAI_Revision_2026/{tables,figures,deliverables}`.
Steps needing internet (gene-symbol mapping via MyGene, Human Protein Atlas
cell-type atlas, GSE193979 download) degrade gracefully and reuse cached tables
when offline.

```

    feature_matrix.parquet      #   254 samples x 16,148 genes (double-logged)
    labels.parquet              #   sample_id -> label (1 = 'Not Cured')
    metadata.parquet            #   cohort/timepoint/subject/characteristics
  expression/
    GSE89403_log2ExpGeneNames_AllSamples.csv.gz   # single-log matrix (for true log2FC)
  models/
    model_bundle.joblib         # frozen model + feature columns + config
DAI_Revision_2026/
  analysis/                     # numbered, ordered analysis steps + common.py
    00_verify_data.py           # cohort/integrity audit
    01_metric_suite.py          # leakage-free baseline metrics (ROC/PR/CI)
    01b_sensitivity_timepoints.py  # quantifies timepoint-leakage inflation
    02_deg_volcano.py / 02b_deg_corrected.py  # DEG (true log2FC from single-log)
    03_shap.py                  # SHAP interpretation + full feature list
    04_deconvolution.py         # marker deconvolution, violins, ML concordance
    05_confounders.py           # sex + bacterial-load adjusted logistic
    06_external_validation.py   # GEO search, exclusion table, portability
    07_celltype_specificity.py  # HPA granulocyte-containing reference
    08_benchmark_table.py       # literature benchmark
    09_recheck.py               # independent verification (LOO, permutation null)
    10_enrichment.py            # pathway over-representation
    11_network.py               # undirected Gaussian graphical network (Fig 4)
  build_manuscript.py / build_supplementary.py / build_response_letter.py
  tables/  figures/  deliverables/   # generated artefacts + submission docs
DATA_PROVENANCE.md              # data sources, licences, how inputs were made
```

## Data provenance
See `DATA_PROVENANCE.md`. Primary cohort: **GSE89403** (Catalysis
treatment-response, whole-blood RNA-seq; Thompson et al. 2017). External
cohort: **GSE193979** (TANDEM). Cell-type reference: **Human Protein Atlas**
blood atlas (Uhlén et al. 2019). All inputs are public.
